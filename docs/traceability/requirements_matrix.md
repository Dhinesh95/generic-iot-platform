## Notes on Verification Status

- **Verified**: An automated test exercises this behavior and passes.
- **Pending compliance/legal sign-off**: The engineering implementation is correct and tested, but regulatory sign-off for a specific deployment jurisdiction has not yet been obtained. Engineering correctness and regulatory sign-off are different things and must not be conflated.
- **Pending water-safety regulatory/public-health sign-off**: The engineering thresholds are based on EPA reference values (MRDL for chlorine, SMCL for pH), but actual safe ranges depend on the specific treatment process, contact time, water temperature, and local regulations. A water-safety engineer or public-health regulatory body must validate these values before field deployment.
- **Deferred — Phase 6.5**: Architecturally mandatory for Industrial domains per Section 4, but deliberately deferred to a separate reviewable phase.
- **Verified (code review)**: The implementation is verified through code review against a well-known algorithm; automated tests exist for the surrounding integration.
